# iLab — прототип приложения

Кликабельный прототип дискаунт-лаборатории iLab: клиент на русском и казахском, режим медсестры, сторис и приглашения,
досдача и уведомления, реклама и фирменный знак.

Открыть: https://altaixah.github.io/ilab-prototype/

Цены, имена, заказы и кабинеты — пример для прототипа, оплата и вход не настоящие.
